# 组合泛化场景 · 中文任务清单

对应总览图 `compo_v2_overview.png`。**判据分两层，缺一不可**：
1. **选对** —— 目标物体的位移必须严格大于所有干扰物（不解析指令的策略拿不到分）；
2. **做对** —— 下表「达成条件」，即任务名承诺的那个终态。

`专家` = 专家演示的产出率，≥ 2/8 才进这张表。
